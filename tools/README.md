## six-box.html — 六格拆解

用瀏覽器打開就得，唔使裝嘢、唔使網絡、唔使帳戶。

打一句「我係乜人，我想部機幫我做乜」，佢會拆成六格：

```
1 睇乜      你要監察咩？點樣攞到？
2 點判斷    乜嘢先算值得你出手？
3 出乜      最後產出係咩形態？
4 去邊      邊度落地？
5 幾時做    人撳？定時？事件觸發？
6 邊度會炸  邊步唔可以自動？
```

每格會標 **沿用** 定 **要新起**，再畀你：要用邊啲 API／CLI／MCP、user flow、五條排除法則跑出嚟嘅危險位、同三條可以即刻貼嘅 prompt。

**重點唔係個工具，係嗰句反轉**：一、二、四格逐盤生意唔同；三、五、六格每次都一樣。你第五、六堂起嘅，就係其餘嗰四格。轉行業唔係由零開始。
